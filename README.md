# mongez-docs

> Astro Starlight site for `mongez.js.org`. Documents `@mongez/atom`, `@mongez/react-atom`, `@mongez/atomic-query`, `@mongez/events`, `@mongez/reinforcements`.

This is a workspace member of the `@mongez/` yarn workspace root. It pulls the `skills/*.md` files from each sibling package and serves them as Starlight pages.

## Setup (first time)

From the workspace root (`@mongez/`):

```sh
yarn install
```

This installs Astro, Starlight, Tailwind, and links the local `@mongez/*` workspace packages. No need for a separate install inside `docs/`.

## Dev

```sh
yarn workspace mongez-docs dev
# or, from this folder:
cd @mongez/docs && yarn dev
```

The dev server runs the `prebuild` chain on startup (sync + llms-full) once, then watches.

## Build

```sh
yarn workspace mongez-docs build
```

Build artifacts go to `dist/`. Cloudflare Pages can be pointed at this folder.

## How content gets here

```
                                                  scripts/sync-skills.ts
@mongez/<pkg>/skills/*.md   ─────────────────────►   src/content/docs/<pkg>/synced/*.md
                                                     (gitignored)

                                                  scripts/build-llms-full.ts
@mongez/<pkg>/llms-full.txt ─────────────────────►   public/llms-full.txt
                                                     (gitignored, ecosystem-level)
```

Both scripts run as `prebuild` in the npm scripts.

Each package's `skills/<file>.md` is wrapped with Starlight frontmatter (title + sidebar order) on the way in. The wrapping rules live in `scripts/sync-skills.ts` — override per-file titles there if a default looks bad.

## Adding a new package

1. Add the package as a workspace member (root `package.json`).
2. Add it to `PACKAGES` in `scripts/sync-skills.ts` and `scripts/build-llms-full.ts`.
3. Add a sidebar section in `astro.config.mjs` pointing at `<package>` directory.
4. (Optional) Write a per-package "Getting Started" page at `src/content/docs/<package>/getting-started.md` — distinct from the synced skill cards. This is the human entry point.

## llms.txt strategy

- `/llms.txt` — hand-authored at `public/llms.txt`. The ecosystem index. AI crawlers find this at the domain root.
- `/llms-full.txt` — generated by `scripts/build-llms-full.ts`. Concatenates per-package `llms-full.txt`. Served at `public/llms-full.txt`.
- `/<package>/llms.txt` and `/<package>/llms-full.txt` — copied from each package by Astro's static serving (set up later as `public/<package>/llms.txt` if we want them at fixed URLs, or via redirects).

The hand-authored root file links to the deeper resources so LLMs can fetch focused per-package content without pulling the whole ecosystem.

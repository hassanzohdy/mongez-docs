## How to suggest a feature

Each `@mongez/*` package has its own GitHub repo and its own issue tracker. Open an issue on the repo that owns the feature — not on a central tracker.

- Find the repo from each package's [ecosystem entry](/ecosystem/) or from the npm registry.
- One feature per issue. Include a use case, not just a wish.
- For cross-package proposals (something that touches three or four packages at once), open on the most-affected repo and link to the others.

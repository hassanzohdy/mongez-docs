## What is Mongez?

Mongez is a family of focused TypeScript packages. Each does one thing well — atom-shaped state management, React routing, form handling, DOM helpers, localization, caching, encryption, and build tooling. Use one package or the whole suite; they compose naturally but stay fully independent.

## Package independence

Every package can be used standalone. `@mongez/reinforcements` is just a utility belt — no peers. `@mongez/atom` is framework-agnostic and works in Vue or plain TypeScript. The React adapters only pull in what they need.

When you adopt one package, the others compose naturally — but nothing forces you to take all of them.

## Built for AI-assisted development

Every package ships with `llms.txt`, `llms-full.txt`, and a `skills/` folder of dense reference cards designed for LLM ingestion. Claude, Cursor, and Copilot get the API shape right on the first try.
